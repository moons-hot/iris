# NASA evidence caches — MED-1 citations

Curated offline extracts for the Mars-transit demo. MED-1 does **not** train models on these datasets. Cards are contextual evidence only (correlation / historical context), never medical causation for the current crew.

| File | Source | Notes |
|------|--------|-------|
| `osdr-inspiration4.json` | [OSD-575](https://osdr.nasa.gov/bio/repo/data/studies/OSD-575), [OSD-656](https://osdr.nasa.gov/bio/repo/data/studies/OSD-656) | Inspiration4 human processed biological summaries (demo cards) |
| `osdr-spaceflight-relationships.json` | NASA OSDR / HRP literature themes | Documented spaceflight → physiological category relationships |
| `eda-cabin-telemetry.json` | [OSDR Environmental Data Application](https://osdr.nasa.gov/bio/env/) style ISS cabin metrics | CO₂ / temp / humidity snippets for spacecraft layer |
| `radlab-radiation.json` | [NASA RadLab](https://visualization.osdr.nasa.gov/radlab/) field schema | Dose rate / flux window labeled as ISS-proxy for mission simulation |

Primary portals:

- OSDR: https://osdr.nasa.gov/
- RadLab visualization / API docs: https://visualization.osdr.nasa.gov/radlab/
